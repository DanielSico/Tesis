WORKFLOW
--------
1. penalization.py
2. fcgr.py
3. control.py

INPUTS
------
-i / --input
    NCBI genomic CDS from an assembly.

-t / --trna
    Plain-text tRNA gene-copy-number table.

-v / --virus
    Virus FASTA file or directory containing Virus FASTA files.

-h / --host
    Host FASTA file or directory containing Host FASTA files.

-j / --sij
    Plain-text file containing:
        s_GU
        s_UG
        s_IC
        s_IA

-s / --seed
    Random seed.

-p / --perm
    Number of synonymous-recoding permutations.

-c / --controls
    Number of matched controls selected per focus gene.



---------------------------------------------------------------------------
penalization.py
---------------------------------------------------------------------------

Workflow
--------
1. Filter CDS sequences.
2. Retain the longest valid CDS per gene.
3. Remove terminal stop codons.
4. Count the 61 sense codons.
5. Calculate one DCBS value per CDS.
6. Read tRNA gene-copy counts from a plain-text file.
7. Build the codon-tRNA compatibility matrix.
8. Evaluate the 625 coarse sij combinations generated by:
       s_GU, s_UG, s_IC, s_IA in
       {0.0, 0.25, 0.50, 0.75, 0.9999}
9. Calculate Spearman correlation with scipy.stats.spearmanr.
10. Select the combination with the highest Spearman rho.
11. Refine that combination by hill climbing with progressively
    smaller steps.

Refinement
----------
The local search starts with a step size of 0.3. At each step size,
all valid neighboring parameter sets produced by adding -step, 0,
or +step to each sij are evaluated. The best improving neighbor is
accepted. If no neighbor improves Spearman rho, the step is divided
by 1.35. Refinement stops when the next step is below 0.001.


---------------------------------------------------------------------------
fcgr.py
---------------------------------------------------------------------------

Workflow
--------
1. Load Virus and Host CDS sequences.
2. Read tRNA gene-copy counts and the optimized sij penalties.
3. Build the codon-tRNA compatibility model and calculate
   relative codon availability weights (wi) and inverse weights (1/wi).
4. Extract non-overlapping codons from each Virus and Host sequence.
5. Construct unweighted relative-frequency FCGR matrices for all
   Virus and Host sequences.
6. Construct inverse-tRNA-availability weighted FCGR matrices
   for the Virus sequences using 1/wi; Host FCGRs remain unweighted.
7. Compare every Virus-Host pair using Spearman correlation,
   Pearson correlation, SSIM, total variation distance and
   Jensen-Shannon distance.
8. Calculate codon competition from the original unweighted
   Virus and Host sense-codon frequencies using the relative
   tRNA availability weights.
9. Correct the Spearman and Pearson p-values using the
   Benjamini-Hochberg procedure and rank the comparisons by
   normalized competition score.
10. Construct Host - weighted Virus difference matrices and
    normalized competition matrices for every Virus-Host pair.
11. Calculate pairwise Pearson correlations among all difference
    matrices and among all competition matrices.
12. Export the unweighted, weighted, SSIM and competition results
    to Excel files.
13. Generate the weighted FCGR comparison and competition images
    at 300 DPI.

Weighted viral fcgr
-------------------
For sense codon i:
    W_i = sum_j [tGCN_ij * (1 - s_ij)]
    w_i = W_i / max(W)
    inverse weight = 1 / w_i
Weighted viral codon contribution:
    n_i / w_i
The weighted viral FCGR is normalized so that its
64 cells sum to 1.
Host FCGRs remain unweighted relative-frequency matrices.

Competition
-----------
Competition is calculated from the ORIGINAL unweighted
Virus and Host sense-codon relative frequencies:
    competition_i =
        H_i * V_i * (1 / w_i)
The inverse availability term is therefore applied only once.

Images
------
Each Virus-Host comparison generates:
    1 weighted comparison image
    1 competition image

OUTPUTS
-------
All outputs are written automatically to:
    results/
Tables:
    unweighted.xlsx
    weighted.xlsx
    SSIM.xlsx
    competition.xlsx
Images:
    results/comparison/
    results/competition/
Only the weighted analysis generates images.


---------------------------------------------------------------------------
control.py
---------------------------------------------------------------------------

Workflow
--------
1. Load Virus and focus Host CDS sequences.
2. Construct a host_global synonymous-codon probability model
   from the supplied focus Host CDSs.
3. Run the synonymous-recoding null test for the focus genes.
4. Select matched background CDS controls using:
       - CDS length
       - GC content
       - GC3 content
       - amino-acid Jensen-Shannon distance
5. Construct a separate host_global synonymous-codon probability
   model from all selected control CDSs.
6. Run the synonymous-recoding null test for the selected controls.
7. Compare every selected control individually with its corresponding
   focus gene.
No averaging or median aggregation across matched controls is performed.

Null test
---------
Modes:
    raw
    penalized
Null model:
    host_global
Host-global synonymous pseudocount:
    1.0
For amino acid a and synonymous codon c:
                         N(a,c) + 1
    P(c | a) = --------------------------------
               sum_j [N(a,c_j) + 1]
Focus and control synonymous probability models are estimated
independently.
Focus null model:
    Estimated from all supplied focus Host CDSs.
Control null model:
    Estimated from all selected control CDSs.
Within each null-test execution, one RNG is initialized before
the mode loop.
RAW mode consumes the first random values.
PENALIZED mode continues from the RNG state left after RAW.
The focus null test and control null test each initialize their
own RNG from the same supplied seed.

Control section
---------------
Minimum background CDS length:
    30 sense codons
Length distance:
    abs(log(control_codons / focus_codons))
GC distance:
    abs(control_GC - focus_GC)
GC3 distance:
    abs(control_GC3 - focus_GC3)
Amino-acid distance:
    Jensen-Shannon distance between amino-acid
    frequency distributions.
Jensen-Shannon zero handling:
    Exact zero-frequency categories contribute zero to their
    corresponding KL term.
    Boolean masks are used.
    No epsilon or pseudocount is added.
Each matching component is standardized independently using
population z-scores within the currently available candidate
pool for each focus gene.
Final matching score:
    z_length
    + z_GC
    + z_GC3
    + z_amino_acid
    + tiny seeded jitter
Lower scores indicate better matches.
Control selection uses its own RNG initialized from the supplied
seed and does not consume null-test random numbers.

Focus-Control Differences
-------------------------
All direct focus-control differences are absolute.
Observed:
    abs_observed_difference
        = abs(focus_observed - control_observed)
Null mean:
    abs_null_mean_difference
        = abs(focus_null_mean - control_null_mean)
Null median:
    abs_null_median_difference
        = abs(focus_null_median - control_null_median)

OUTPUTS
-------
The files are written directly beside this script.
null_test.xlsx
    Focus
        Null-test results for focus genes.
    Control
        Individual focus-control comparison results.
controls.xlsx
    Genes_control
        Matched-control selection report.
